## 🤖 Multi-Agent Orchestration Frameworks
*Frameworks designed for orchestrating complex, role-based, and stateful multi-agent workflows.*

* **[CrewAI](https://github.com/joaomdmoura/crewAI)** — Production framework for orchestrating role-playing, autonomous AI agents.
* **[AutoGen (Microsoft)](https://github.com/microsoft/autogen)** — Multi-agent conversation framework enabling next-gen LLM applications.
* **[LangGraph (LangChain)](https://github.com/langchain-ai/langgraph)** — Build resilient, stateful multi-agent workflows using graph-based primitives.
* **[LlamaIndex Workflows](https://github.com/run-llama/llama_index)** — Event-driven orchestration layer for complex agentic data processing.
* **[Semantic Kernel (Microsoft)](https://github.com/microsoft/semantic-kernel)** — Enterprise orchestration SDK integrating LLMs with native C#, Python, and Java code.
* **[MetaGPT](https://github.com/geekan/MetaGPT)** — Multi-agent framework assigning human-like SOP roles (Product Manager, Architect, Engineer) to LLMs.

## 💻 Autonomous Coding & Developer Agents
*CLI tools, IDE integrations, and autonomous agents that write, refactor, and test software.*

* **[Claude Code (Anthropic)](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/overview)** — Agentic terminal CLI that writes code, runs terminal commands, navigates codebases, and solves git issues autonomously.
* **[Google Antigravity](https://agenticspulse.com)** — Advanced agentic coding system designed for deep-reasoning pair programming and autonomous software engineering.
* **[Cursor](https://www.cursor.com/)** — AI-first code editor built for seamless agentic workflows and whole-repo context.
* **[Windsurf (Codeium)](https://codeium.com/windsurf)** — Next-gen AI IDE powered by Cascade flows and real-time codebase indexing.
* **[Aider](https://github.com/paul-gauthier/aider)** — AI pair programming tool in your terminal that directly commits to local git repos.
* **[OpenHands (formerly OpenDevin)](https://github.com/All-Hands-AI/OpenHands)** — Open-source platform for autonomous software development agents.

## 🌐 Browser & Desktop Automation Agents
*Agents capable of web scraping, interacting with web pages, and executing desktop workflows.*

* **[Browserbase / Stagehand](https://github.com/browserbase/stagehand)** — An AI web browsing framework for reliable, automated browser navigation.
* **[Anthropic Computer Use](https://docs.anthropic.com/en/docs/build-with-claude/computer-use)** — API capability allowing Claude to control mouse/keyboard and interact directly with screen interfaces.
* **[Browser-Use](https://github.com/browser-use/browser-use)** — Open-source web automation library connecting LLMs directly to browser sessions.
* **[Playwright AI](https://playwright.dev/)** — Headless browser orchestration paired with LLM reasoning agents.

## 🧠 Agent Memory, RAG & Vector Layers
*Persistent memory layers, knowledge graphs, and storage backends for long-term agent state.*

* **[Mem0](https://github.com/mem0ai/mem0)** — The memory layer for Personalized AI Agents and LLM assistants.
* **[Zep](https://github.com/getzep/zep)** — Fast, scalable memory and knowledge graph store for production AI agents.
* **[Qdrant](https://github.com/qdrant/qdrant)** — Vector similarity search engine designed for high-load production RAG systems.
* **[ChromaDB](https://github.com/chroma-core/chroma)** — Lightweight, open-source embedding database for prototyping agentic memory.

## 🔍 Agent Evaluation, Observability & Tracing
*Monitoring, debugging, and tracing agent reasoning steps and tool execution.*

* **[LangSmith](https://www.langchain.com/langsmith)** — Observability and evaluation platform for LLM applications and agent steps.
* **[Arize Phoenix](https://github.com/Arize-ai/phoenix)** — Open-source AI observability for tracing, evals, and agent latency analysis.
* **[Helicone](https://github.com/Helicone/helicone)** — LLM cost monitoring, caching, and rate-limiting proxy for agent workflows.
* **[Braintrust](https://www.braintrustdata.com/)** — Enterprise-grade evaluation platform for assessing autonomous agent reliability.
